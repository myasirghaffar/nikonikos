# Nikonikos Frontend

Vite + React project scaffold prepared for:

- Public website routes: `/`, `/about`, `/contact`
- Single-role admin panel: `/admin/dashboard`
- Admin auth route: `/login`

## Theme Palette

The project theme is based on the provided screenshot palette:

- `#000000`
- `#141414`
- `#1A1A1A`
- `#9CA3AF`
- `#DC2626`
- `#F3F4F6`
- `#FFFFFF`

Shared Tailwind tokens live in `tailwind.config.js` under `theme.extend.colors.app`.
